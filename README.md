# Digital Music Store

A web-based music store project built with HTML, CSS, and JavaScript.

## Project Structure
- **css/** - Stylesheets
- **js/** - JavaScript files
- **assets/** - Images, fonts, and other media
- **bin/** - Binary files (ignored)
- **modules/** - Node modules (ignored)

## Description
This project is a Digital Music Store website for the DevOps Git Flow assignment.
